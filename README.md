# Grant Publishing Co.

Installable WordPress plugin **4.4.0** adds contextual internal links, two documented HTML case studies, service proof, stronger About positioning and practical FAQs. It preserves the approved design and the 22 existing template/layout pairs, forms, legal copy, testimonials, URLs and brand assets.

**[Download the installable plugin ZIP](https://github.com/abdulqudusgbolagade/GrantPublishing-Co/raw/refs/heads/main/releases/4.4.0/grant-publishing-site-4.4.0.zip)**

If downloading fails, [open the ZIP on GitHub](https://github.com/abdulqudusgbolagade/GrantPublishing-Co/blob/main/releases/4.4.0/grant-publishing-site-4.4.0.zip) and select **Download raw file**. Upload this plugin ZIP rather than the entire repository.

The update creates `/case-studies/`, `/case-studies/my-dear-grandfather/`, `/case-studies/luma-the-sleepy-star/` and `/faq/`. Existing Insights lead naturally to services, relevant documented proof and the existing Free Book Assessment. Manual Yoast values remain authoritative.

The plugin is tested locally in actual WordPress, Elementor and Yoast. **Production installation is pending.** An administrator’s dashboard visit creates only the four missing pages. Existing content and private Web3Forms settings are preserved. Do not bulk-convert installed Elementor pages for this update.
