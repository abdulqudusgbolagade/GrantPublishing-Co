# Grant Publishing Co. 4.5.0

Requires WordPress 6.0+ and PHP 7.4+. Elementor 3.16+ supports native editing; Grant shortcodes also work without Elementor. This update preserves the approved website design.

## Install on the existing site

1. Back up production files and database. Keep the previous 4.4.0 ZIP.
2. Upload `grant-publishing-site-4.5.0.zip` under Plugins → Add New → Upload Plugin. Replace the existing plugin and activate if necessary.
3. Visit the dashboard as an eligible administrator, then review Tools → Grant Website Setup. Existing pages, Elementor data, manual Yoast fields and private delivery settings are preserved. Scoped cleanup drafts only an exact untouched starter post with a private backup, and two authority articles are saved as editable **Draft** pages under Insights. Conflicts are reported rather than overwritten.
4. Clear WordPress, host and CDN caches using existing controls. Confirm assets use `ver=4.5.0`. Keep Contact/Assessment form tokens fresh using the existing cache exclusions. Do not bulk-convert or restore native layouts or reset Web3Forms settings.
5. Check framework links, mobile navigation, service preselection, consent/privacy links, original case studies/PDFs and one title/H1 per page while logged out. Review the two articles before publishing them. Publication can add their rows to the existing Insights index; drafts remain absent from public navigation and sitemaps.

## Changes and scope

The GRANT Framework replaces the existing Home process copy in place and expands About’s approach at `/about/#grant-framework`. Shared exact stage names are used on relevant services and documented case studies. Each project includes only agreed stages; tracking requires a baseline, timeframe and client-authorised data within scope.

Luma remains cover redesign/interior formatting and print-file delivery, without KDP upload or marketing outcomes. My Dear Grandfather remains qualified listing/description/research evidence, without causal sales/ranking claims. The publicly approved Kathryn’s Beach screenshot illustrates A+ presentation, with no commercial performance claim.

Closing CTAs on Formatting, Cover Design, Publishing Support and Luma now open Contact with actual existing service selections. Amazon links remain optional. Free Assessment stays an initial public Amazon-visible diagnostic, not a full five-stage engagement. Privacy links are placed after existing consent. No required field or automatic subscription is added.

The three existing Insights credit confirmed author AbdulQudus Tella and their actual original publication dates. Two complete authority articles are prepared as drafts only. Protected PHP source files do not expose their unreviewed body text on direct requests.

WordPress/Canvas/Yoast title ownership is corrected at supported lifecycle stages, without output buffering or changing saved manual metadata. Repeated wording already present in expanded Yoast titles is preserved for owner review. Existing routing repairs, footer/legal links, FAQ, case-study hub, testimonials, logos/favicon, founder image and broader service positioning remain.

Web3Forms remains server-side using private settings. Provider acceptance is distinct from inbox receipt. Uncertain submissions preserve visitor information and ask them to check before sending again. No real access key or production credential is bundled.
